# Basic Number Programs using Java 🔢

This repository contains simple **Java programs** based on number theory and basic mathematical logic.  
It is designed for beginners learning **Java programming** and practicing fundamental problem-solving techniques.

---

## 📂 Programs Included

1. **Armstrong Number (`armstrong number.java`)**
   - Checks whether a number is an Armstrong number.  
   - Example: 153 = 1³ + 5³ + 3³.

2. **Krishnamurthy Number (`krishnamurthy.java`)**
   - Checks if a number is equal to the sum of factorial of its digits.  
   - Example: 145 = 1! + 4! + 5!.

3. **LCM of Two Numbers (`lcm number.java`)**
   - Finds the Least Common Multiple (LCM) of two numbers.

4. **Palindrome Number (`palindrome number.java`)**
   - Checks whether a number reads the same backward and forward.  
   - Example: 121, 1331.

5. **Spy Number (`spy number.java`)**
   - A number is a Spy Number if the sum of its digits equals the product of its digits.  
   - Example: 112 → Sum = 1+1+2=4, Product = 1×1×2=2 → Not Spy.

6. **Sum of Even Numbers in an Array (`sum of even nos. in array.java`)**
   - Finds and adds all even numbers present in an array.
